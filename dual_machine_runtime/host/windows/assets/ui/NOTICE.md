# UI icon assets

The icons in this directory are rasterized build assets from Microsoft Fluent UI System Icons,
package `@fluentui/svg-icons` version 1.1.333. The upstream project is
<https://github.com/microsoft/fluentui-system-icons> and is licensed under the MIT License.

The original SVG names used by the native Windows host are recorded in the UI implementation
change history. Both the PNG design sources and ICO resources are retained so the single EXE
build can embed the real icon assets without a runtime asset directory.
